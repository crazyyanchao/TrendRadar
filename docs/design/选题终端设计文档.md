# 张三·选题终端（TOPIC TERMINAL v1.0）原型设计文字稿

设计核心要求：个性化 + 信息密集 + 模块化

## 一、整体布局（浅色玻璃态 · 三栏式）

| 区域 | 位置 | 尺寸建议 | 核心内容 |

|------|------|----------|----------|

| **顶部导航栏** | 全屏顶部 | 高64px | 用户个性名称 + 实时时间/日期 + 在线状态 + 版本号 + 设置入口 |

| **左侧主栏** | 左上 + 左下 | 宽35% | 今日综合选题TOP10（核心列表） + 权威新闻源头条 |

| **中间列** | 中部 | 宽35% | 多平台实时热榜流（微博/知乎/抖音并列展示） |

| **右侧面板** | 右侧 | 宽30% | 详情预览面板（点击选题后展示完整信息） |

## 二、配色方案（浅色玻璃态 · 金融科技风）

| 元素 | 色值 | 说明 |

|------|------|------|

| 全局背景 | `#F0F4F8` → `#E8EDF3` | 浅灰蓝渐变，柔和护眼 |

| 卡片/面板 | `rgba(255,255,255,0.65)` + `backdrop-filter: blur(20px)` | 玻璃态毛玻璃效果 |

| 卡片边框 | `rgba(255,255,255,0.3)` | 极淡白边，增加层次 |

| 主文字 | `#1A2332` | 深空色，保证可读性 |

| 辅助文字 | `#5A6C7D` | 中灰色 |

| 强调色/品牌色 | 渐变蓝紫 `#4A7CF7` → `#6C5CE7` | 金融科技感 |

| 评分高亮 | 橙红 `#FF6B4A` | 醒目但克制 |

| 阴影 | `0 8px 32px rgba(0,0,0,0.06)` | 轻阴影，保持通透感 |

## 三、各区域详细设计

### 1. 顶部导航栏（用户个性化入口）

**布局**（从左至右）：

| 位置 | 元素 | 说明 |

|------|------|------|

| 左侧 | **用户个性名称（可编辑）** | 默认"路口大爷"，点击后出现输入框，用户可修改为自己昵称，后缀固定为"·选题终端（TOPIC TERMINAL v1.0）" |

| 左侧 | 小铅笔图标 | 悬浮显示"点击修改名称"，点击触发编辑 |

| 中部（右对齐） | 实时时钟 + 日期 | 格式`2026-08-27 14:32:08 周四` |

| 右侧 | 在线状态绿点 | 绿色=数据源正常，黄色=部分异常，红色=离线 |

| 右侧 | 版本号 | 显示"v1.0" |

| 最右 | ⚙️ 设置图标 | 点击弹出设置面板（兴趣点配置入口） |

**交互**：

- 点击个性名称 → 弹出输入框 → 用户输入新名称 → 回车确认 → 全局更新显示

- 名称保存在本地或用户配置中

### 2. 左上区域：今日综合选题TOP10（核心决策区）

**定位**：基于全网原始数据 × 用户兴趣过滤后，AI重新生成的专属选题榜

**展示列表**：

| 列字段 | 说明 |

|--------|------|

| 排名序号 | 01-10，带颜色渐变（前三名特殊高亮） |

| 选题标题 | 热点事件简短标题 |

| 事件类型 | 标签样式：货币政策 / 地缘政治 / 行业监管 / 财报数据 / 科技前沿 等 |

| 综合评分 | 0-100分，环形进度条展示 |

| 来源 | 小图标 + 平台名（微博/知乎/抖音/路透/财新等） |

| 匹配度 | 🔥 显示与用户兴趣的匹配程度（高/中/低） |

| 状态 | 切换按钮：**推荐** / **待看** / **已阅** |

**交互**：点击任一选题 → 右侧面板展开详情

**详情展开内容**（右侧面板展示）：

- 选题摘要（AI生成，100-200字）

- 关键要素（人物/机构/时间/金额等）

- 可操作性（高/中/低 + 理由）

- 曝光预判（预估阅读/播放量级）

- 预估时长（创作所需小时数）

- 兴趣匹配说明（AI解释"为什么推荐给你"）

- 素材链接（原始新闻/视频/研报链接集合）

### 3. 左下区域：权威新闻源头条（原始素材池）

- 自动抓取权威财经媒体（路透、彭博、财新、华尔街见闻、券商研报等）

- 以**精简时间流**展示最近24小时头条

- 每条显示：标题 + 媒体来源 + 时间

- 作用：作为选题的**原始素材源头**，点击展开预览或跳转原文

- 顶部有**筛选开关**："仅显示与我兴趣相关"，开启后过滤原始流

### 4. 中间区域：热点选题多平台实时流（并列热榜）

**定位**：展示各平台原始热榜，供用户横向对比

| 平台 | 展示内容 |

|------|----------|

| 微博热榜 | 当前热搜词 + 热度值 |

| 知乎热榜 | 当前热榜问题 + 关注量/回答量 |

| 抖音热榜 | 当前热点话题 + 播放量/话题指数 |

**交互**：

- 每个平台独立卡片，各自滚动更新

- 每条热榜条目旁显示 **"兴趣匹配"小标签**（绿色高亮表示与用户兴趣相关）

- 点击任一热榜条目 → 可"加入选题库"或"查看详情"（关联右侧面板）

### 5. 右侧面板：详情预览面板（研判工作区）

**触发方式**：点击左侧TOP10选题 或 中间热榜条目

**展示内容**：

- 完整选题详情（标题、摘要、要素、评分细项）

- 兴趣匹配分析（AI说明该选题与用户关注点的关联）

- 参考素材（原始新闻链接、视频、研报片段）

- 研判笔记（AI生成：切入点建议 + 机会分析 + 风险提示）

- 用户可**手动编辑笔记**（个人研判记录）

- 底部操作按钮`标记为已处理` / `加入待看` / `导出选题`

## 四、核心功能模块（共7项）

| 序号 | 功能模块 | 具体能力 |

|------|----------|----------|

| 1 | **用户个性化设置** | 支持修改顶部个性名称；支持设置关注关键词/兴趣描述，作为选题过滤依据 |

| 2 | **全网热点自动采集** | 定时抓取微博/知乎/抖音热榜 + 财经新闻源 + 券商研报，去重过滤 |

| 3 | **兴趣过滤引擎** | 基于用户设置的关键词/描述，对原始数据进行相关性匹配和过滤 |

| 4 | **AI打分与智能排序** | 每条热点综合热度 + 时效性 + 与用户兴趣匹配度 → 输出0-100分，按分排序 |

| 5 | **AI选题深度研判** | 自动生成摘要、切入点建议、机会与风险分析、兴趣匹配说明，附原始链接 |

| 6 | **多平台热榜统一视图** | 微博/知乎/抖音热榜并列展示，标注兴趣匹配项，辅助跨平台对比 |

| 7 | **选题状态管理** | 支持标记"推荐"/"待看"/"已阅"，形成个人选题库，支持筛选与归档 |

## 五、用户工作流（典型使用路径）

```

① 首次使用 → 点击顶部设置图标 → 输入个人昵称 + 设置关注关键词/兴趣描述

         ↓

② 系统自动基于兴趣过滤全网数据 → 生成个性化TOP10选题列表

         ↓

③ 查看TOP10 → 点击感兴趣选题 → 右侧阅读AI研判 + 兴趣匹配说明 + 原始素材

         ↓

④ 如需多平台验证 → 看中间热榜横向对比 → 关注绿色高亮（兴趣匹配项）

         ↓

⑤ 判断是否采用 → 标记状态（推荐/待看/已阅）→ 或导出选题开始创作

         ↓

⑥ 随时可调整兴趣设置 → 系统实时重新生成选题列表

```

## 六、设置面板（弹窗）详细设计

**触发**：点击顶部 ⚙️ 图标

**内容**：

| 配置项 | 控件类型 | 说明 |

|--------|----------|------|

| 我的昵称 | 文本输入框 | 修改顶部显示名称，默认"路口大爷" |

| 关注关键词 | Tag输入框 | 输入后回车生成标签，如`美联储` `CPI` `黄金` `A股` `科技监管` |

| 兴趣描述 | 多行文本框 | 自然语言描述，如："我是财经记者，主要关注宏观经济政策、央行动向、资本市场波动" |

| 数据源偏好 | 多选开关 | 微博 / 知乎 / 抖音 / 财经媒体 / 券商研报（可勾选） |

| 保存按钮 | 主操作按钮 | 保存后立即重新生成选题列表 |

## 七、设计语言总结（一句话）

&gt; **浅色玻璃态 × 金融科技感 × 个性化兴趣引擎**：一个可自定义昵称和关注范围的AI选题看板，全网数据经用户兴趣过滤后，生成专属选题推荐，实现"千人千面"的选题工作台。

## ✅ 实现注记（2026-08）

本设计稿的 v1.0 已实现。与原稿的对应关系和差异说明：

- **启动方式**：本地 `python -m trendradar --serve`；Docker cron 模式随 entrypoint 自动启动。默认地址 `http://localhost:8090`（8080 已被报告 Web 服务器占用）
- **代码位置**：服务端 API 位于 `trendradar/webapp/`（server / reader / scoring / research / store / tasks），前端页面位于 `trendradar/webapp/static/`
- **「权威新闻源头条」数据源差异**：路透、彭博不在项目现有数据源内，v1 采用华尔街见闻 / 财联社 / 澎湃新闻 / 凤凰网四个已接入热榜源 + RSS 订阅合并成时间流
- **昵称与设置持久化**：保存在 `output/terminal/profile.json`（因 Docker 中 config 目录为只读挂载），AI 打分所需的兴趣描述以参数注入现有筛选管道
- **状态灯语义**：绿=全部抓取成功且 90 分钟内有数据；黄=部分失败或数据略旧；红=当天无记录或超过 24 小时未更新
- 使用说明与环境变量详见 README「📡 AI 选题终端」章节
